Advanced Network Scanner

A Python-based tool for network device discovery, built with Tkinter and Scapy.

🔍 Overview

This application, written in Python, provides a graphical interface (Tkinter) for scanning local networks. It leverages the powerful Scapy library to send ARP requests to a specified IP range (e.g., 192.168.1.1/24) to discover active devices. Additionally, it uses standard Python networking modules for hostname resolution and basic ping checks to determine the status (Online/Offline) of the discovered hosts.

✨ Key Features

  • GUI Interface: Easy-to-use graphical user interface built with Tkinter.
  • ARP Scanning (Scapy): Efficient network discovery using ARP packets to find IP and MAC addresses.
  • IP Range Auto-Detection: Automatically suggests the local network range (e.g., 192.168.1.1/24).
  • Host Status Check: Pings each discovered host to determine if it is "Online" or "Offline".
  • Hostname Resolution: Attempts to resolve the hostname for each IP address.
  • Data Export: Results can be exported to a CSV file.
  • Interactive Results Table:
    • Results displayed in a sortable Treeview widget.
    • Right-Click Context Menu on IP address for copying the IP or opening it in a web browser (as http://IP_Address).
    • Cursor changes to a hand when hovering over the IP column.
  • Multi-Threading: The network scan runs in a separate thread to keep the GUI responsive.

⚙️ Technical Implementation Details

The core functionality relies on the following key components:

1. Network Discovery (Scapy - scan_network method)

The tool uses an ARP (Address Resolution Protocol) sweep for fast discovery. It crafts an Ethernet frame with the destination MAC set to the broadcast address (ff:ff:ff:ff:ff:ff) and an ARP packet targeting the IP range.

ans, _ = srp(Ether(dst="ff:ff:ff:ff:ff:ff") / ARP(pdst=ip_range), timeout=3, verbose=False)

The ans variable contains the list of answered packets, providing the IP (received.psrc) and MAC (received.hwsrc) addresses.

2. Host Status Check (Subprocess - ping_host method)

To confirm the device is responding and to determine its status (Online/Offline), the code executes a native system ping command, supporting both Windows (-n 1) and Unix-like systems (-c 1).

param = '-n' if platform.system().lower() == 'windows' else '-c'
command = ['ping', param, '1', ip]
response = subprocess.run(command, ...)

3. GUI Responsiveness (Threading)

Since network scanning is a blocking operation, the scan_network method is run in a separate daemon thread (start_scan_thread) to prevent the Tkinter GUI from freezing. All GUI updates (like progress bar and table updates) are safely scheduled back onto the main thread using self.root.after(0, ...).
